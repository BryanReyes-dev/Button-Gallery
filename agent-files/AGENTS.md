# Agent Instructions — Button Gallery

Button Gallery is an evolving UI component project. The current implementation is a small HTML/CSS/JavaScript button gallery; the planned direction is a full Next.js implementation.

## Before Working

1. Read `agent-files/Agents_Context.md` for current working state.
2. Read `agent-files/ARCHITECTURE.md` for finalized decisions.
3. Inspect the existing implementation before changing it.
4. Do not assume the planned Next.js migration has been implemented unless the source confirms it.

## Documentation Authority

- `ARCHITECTURE.md` contains finalized architectural decisions.
- `Agents_Context.md` contains temporary working context, discoveries, plans, and open questions.
- Do not silently turn a proposal into an architectural decision.

## Implementation Rules

- Preserve working behavior unless the task requires changing it.
- Keep project-specific implementation details in the source rather than duplicating them in agent documentation.
- When the Next.js migration begins, update the architecture only after decisions are finalized and approved.
- Do not make unrelated changes while performing structural or documentation work.
