# Button Gallery

Button Gallery is a UI button gallery project. The current implementation is a small HTML/CSS/JavaScript prototype, with a full Next.js implementation planned.

## Agent Files

The `agent-files/` directory contains documentation for AI coding agents. It is separate from this README and source code: `AGENTS.md` contains agent instructions, `ARCHITECTURE.md` records finalized architecture, `Agents_Context.md` stores short-term working context, and `CLAUDE.md` provides the Claude entry point.
